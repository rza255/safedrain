# SafeDrain Privacy Policy

Effective date: September 30, 2026

SafeDrain is a behavioral plugin and skill that helps compatible AI agents monitor native
runtime usage limits, adjust work cadence, and stop at recoverable checkpoints before
quota exhaustion.

## Data collection

SafeDrain does not operate its own server or backend and does not independently collect,
transmit, sell, or store personal data.

SafeDrain does not provide its own telemetry or usage-monitoring service.

When SafeDrain is used, the host AI agent may access runtime usage or quota information
through capabilities already provided by the host platform. SafeDrain only provides
instructions for how the agent should use that information.

## Purpose

Runtime quota information is used only by the active host agent to guide work cadence,
work-unit size, and recoverable stopping behavior.

## Data sharing

SafeDrain does not send user data, prompts, project files, quota information, or other
usage information to the SafeDrain developer or to any SafeDrain-operated third party.

## Data retention

SafeDrain does not maintain an external database or service and therefore does not
independently retain user data.

Any conversation history, files, runtime information, logs, or other data handled by
the host platform remain subject to that platform's own privacy and retention policies.

## Third-party services

SafeDrain does not require an external MCP server or other SafeDrain-operated network
service.

If the user or host agent independently uses other tools, plugins, services, or external
systems while SafeDrain is active, those services are governed by their own privacy
policies.

## User controls

Users can disable or uninstall SafeDrain at any time through the host application's
plugin or skill controls.

## Changes to this policy

If SafeDrain's architecture changes in a way that introduces data collection, external
services, telemetry, or storage, this privacy policy will be updated accordingly.
